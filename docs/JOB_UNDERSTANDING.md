## Extracted Job Description (Senior AI Engineer – Founding Team)

```
Job Description: Senior AI Engineer — Founding Team
Company: Redrob AI (Series A AI-native talent intelligence platform)
Location: Pune/Noida, India (Hybrid — flexible cadence) | Open to relocation candidates from Tier-1 Indian cities
Employment Type: Full-time
Experience Required: 5–9 years (see "what we mean by this" below)

We need someone who is simultaneously comfortable with two things that sound contradictory:
- Deep technical depth in modern ML systems — embeddings, retrieval, ranking, LLMs, fine‑tuning.
- Scrappy product‑engineering attitude — willing to ship a working ranker in a week even if the underlying ML is "obviously suboptimal," because we need to learn from real users before we know what to actually optimize for.

Key responsibilities:
- Own the intelligence layer (ranking, retrieval, matching) of Redrob's product.
- Audit and improve the current BM25 + rule‑based system.
- Ship a v2 ranking system (embeddings, hybrid retrieval, possible LLM re‑ranking).
- Set up evaluation infrastructure (offline benchmarks, online A/B testing, recruiter‑feedback loops).
- Mentor a growing team and collaborate with PMs.

Disqualifiers:
- Pure research background without production deployment.
- Recent (≤12 months) LangChain‑only projects without prior ML production experience.
- No production code in the last 18 months.

Skills inventory (high‑priority):
- Production experience with embeddings‑based retrieval (sentence‑transformers, BGE, E5, etc.).
- Experience with vector databases/hybrid search (FAISS, Qdrant, Pinecone, Elasticsearch, etc.).
- Strong Python skills.
- Designing evaluation frameworks (NDCG, MRR, MAP, A/B testing).

Nice‑to‑have (not required):
- LLM fine‑tuning (LoRA, QLoRA, PEFT).
- Learning‑to‑rank models (XGBoost, neural).
- HR‑tech or recruiting domain experience.
- Distributed systems or large‑scale inference optimisation.
```

## High‑Level Interpretation for Ranking
- **Technical depth** → prioritize candidates with **production‑grade embedding & retrieval experience**.
- **Scrappy product mindset** → give weight to **rapid delivery history** and **shipping MVPs**.
- **Behavioural signals** (Redrob activity, response rate) are explicitly mentioned as important.
- **Location constraint** → Pune/Noida or Tier‑1 Indian cities.
- **Disqualifiers** → hard filters that must zero‑out a candidate's score.
